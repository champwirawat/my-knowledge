# Dust (du-dust)

`dust` (หรือ `du-dust`) เป็นเครื่องมือสำหรับตรวจสอบการใช้งานพื้นที่ดิสก์ (Disk Usage) ที่เขียนด้วยภาษา Rust โดยเป็นทางเลือกสมัยใหม่ทดแทนคำสั่ง `du` แบบดั้งเดิม ซึ่งแสดงผลลัพธ์เป็นแบบ tree hierarchy พร้อมแถบสีและกราฟิกที่สวยงามและเข้าใจง่าย

--------------------------------------------------------------------------------

## ⚙️ การติดตั้ง (Installation)

เลือกติดตั้งตามระบบปฏิบัติการที่ใช้งาน:

### macOS (Homebrew)
```sh
brew install dust
```

### Windows (Scoop / Winget / Cargo)
```sh
# ติดตั้งผ่าน Scoop
scoop install dust

# ติดตั้งผ่าน Winget
winget install --id=bootandy.dust -e

# ติดตั้งผ่าน Cargo
cargo install du-dust
```

### Linux (Snap / Cargo)
```sh
# ติดตั้งผ่าน Snap
snap install dust

# หรือติดตั้งผ่าน Cargo
cargo install du-dust
```

## ⚙️ การใช้งาน (Usage)

### 1. ตรวจสอบพื้นที่ในโฟลเดอร์ปัจจุบัน
เพียงพิมพ์คำสั่ง `dust` ระบบจะแสดงผลโครงสร้างไฟล์และโฟลเดอร์ที่กินพื้นที่มากที่สุด เรียงจากมากไปน้อย:
```sh
dust
```

### 2. ตรวจสอบพื้นที่ในโฟลเดอร์ที่ระบุ
```sh
dust /path/to/directory
```

### 3. จำกัดความลึกในการแสดงผล (Depth)
หากไม่ต้องการให้แสดงผลโฟลเดอร์ย่อยลึกเกินไป สามารถระบุความลึกได้ด้วย `-d` หรือ `--depth`:
```sh
# แสดงผลลึกไม่เกิน 2 ชั้น
dust -d 2
```

### 4. แสดงเฉพาะรายการที่ใช้พื้นที่มากที่สุด N อันดับแรก
```sh
# แสดงผล 10 อันดับแรก
dust -n 10
```

### 5. แสดงเฉพาะโฟลเดอร์ (Directory) หรือเฉพาะไฟล์ (File)
```sh
# แสดงเฉพาะ directory ไม่แสดงรายไฟล์ย่อย
dust -D

# แสดงเฉพาะไฟล์
dust -F
```

### 6. ค้นหาแบบละเว้น (Exclude) ไฟล์หรือโฟลเดอร์ที่ไม่ต้องการ
สามารถใช้ Regex ในการละเว้นไฟล์ได้โดยใช้ `-x`:
```sh
# ละเว้นไฟล์ .tmp
dust -x "\.tmp$"
```
