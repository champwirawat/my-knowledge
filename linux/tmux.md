# คู่มือการใช้งาน Tmux (Terminal Multiplexer)

**Tmux (Terminal Multiplexer)** คือเครื่องมือที่ทรงพลังสำหรับนักพัฒนาและผู้ดูแลระบบ (SysAdmin) ช่วยให้เราสามารถเปิดและจัดการหน้าจอ Terminal ย่อย ๆ หลายหน้าต่าง (Windows/Panes) ได้พร้อมกันภายใต้หน้าต่าง Terminal เดียว และที่สำคัญคือ มีฟีเจอร์เด่นเรื่องการ **Detach** (ถอดโปรเซสทำงานเบื้องหลัง) และ **Attach** (เชื่อมต่อกลับเข้ามาทำงานต่อ) ทำให้คำสั่งหรือเซิร์ฟเวอร์ที่เราเปิดไว้ยังคงทำงานอยู่แม้ว่าเราจะปิดโปรแกรม Terminal หรือการเชื่อมต่อ SSH หลุดไปก็ตาม

---

## 💡 แนวคิดสำคัญของ Tmux (Core Concepts)

การทำงานของ Tmux จะแบ่งสถาปัตยกรรมออกเป็น 3 ระดับหลัก ๆ ดังนี้:

```text
           ┌────────────────────────────────────────┐
           │              Tmux Server               │
           └────────────────────────────────────────┘
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
 ┌─────────────────────┐               ┌─────────────────────┐
 │   Session (งานที่ 1)  │               │   Session (งานที่ 2)  │
 └─────────────────────┘               └─────────────────────┘
            │
      ┌─────┴─────┐
      ▼           ▼
 ┌─────────┐ ┌─────────┐
 │Window 1 │ │Window 2 │ (หน้าจอ Tab ต่าง ๆ)
 └─────────┘ └─────────┘
      │
  ┌───┴───┐
  ▼       ▼
┌───┐   ┌───┐
│P1 │   │P2 │ (ช่องย่อยแบ่งหน้าจอ Panes)
└───┘   └───┘
```

1. **Session (เซสชัน):** เสมือนพื้นที่ทำงานหลัก (Workspace) สำหรับ 1 โครงการหรือ 1 งาน โดยภายใน 1 Session สามารถมีหลาย Windows ได้ และ Session นี้จะยังคงรันอยู่บน Server ต่อไปจนกว่าเราจะสั่งสั่งปิด หรือปิดเครื่อง
2. **Window (หน้าต่าง):** หน้าจอหลักเปรียบเสมือน Tab ของ Browser ภายใน Session เดียวกัน โดยเราสามารถสลับสับเปลี่ยนไปมาได้
3. **Pane (ช่องย่อย):** การแบ่งหน้าจอใน 1 Window ออกเป็นส่วนย่อย ๆ เช่น แบ่งครึ่งซ้าย-ขวา หรือบน-ล่าง เพื่อดูไฟล์คอนฟิกไปพร้อม ๆ กับรันคำสั่ง

## 📥 การติดตั้ง (Installation)

คุณสามารถติดตั้ง Tmux ได้ง่าย ๆ บนระบบปฏิบัติการต่าง ๆ ด้วยคำสั่งดังนี้:

| OS | คำสั่งการติดตั้ง |
|---|---|
| **macOS** | `brew install tmux` |
| **Ubuntu / Debian** | `sudo apt update && sudo apt install tmux` |
| **CentOS / RHEL** | `sudo dnf install tmux` (หรือ `yum install tmux`) |
| **Arch Linux** | `sudo pacman -S tmux` |

## 🔑 ปุ่ม Prefix (หัวใจสำคัญของ Tmux)

คำสั่งลัด (Shortcuts) เกือบทั้งหมดใน Tmux จะต้องกดปุ่มนำทางหลักที่เรียกว่า **Prefix key** เสียก่อน เพื่อบอกให้ระบบรู้ว่าเราต้องการส่งคำสั่งไปยัง Tmux ไม่ใช่ส่งไปยัง Shell ปกติ

* ปุ่ม Prefix เริ่มต้นของ Tmux คือ: `Ctrl + b` (ในคู่มือนี้จะเขียนย่อว่า **`C-b`**)
* **วิธีใช้งาน:** กด `Ctrl` ค้างไว้แล้วกด `b` จากนั้นปล่อยมือทั้งหมด แล้วจึงกดปุ่มคำสั่งอื่นตามทันที (เช่น `C-b` แล้วตามด้วย `c` เพื่อสร้าง Window ใหม่)

## 📋 ตารางสรุปคำสั่งและปุ่มลัด (Cheat Sheet)

### 1. การจัดการ Session (ควบคุมผ่าน Terminal ปกติ)

| คำสั่ง (นอก Tmux) | คำอธิบาย |
|---|---|
| `tmux` | เริ่มใช้งาน Tmux โดยสร้าง Session ใหม่แบบสุ่มตัวเลข |
| `tmux new -s <name>` | สร้าง Session ใหม่โดยระบุชื่อที่คุณต้องการ (แนะนำ) |
| `tmux ls` | แสดงรายชื่อ Session ทั้งหมดที่เปิดอยู่ |
| `tmux attach -t <name>` | เชื่อมต่อเข้าสู่ Session ตามชื่อระบุ (ย่อเป็น `tmux a -t <name>` ได้) |
| `tmux rename-session -t <old> <new>` | เปลี่ยนชื่อ Session จากชื่อเดิมเป็นชื่อใหม่ |
| `tmux kill-session -t <name>` | ปิด Session ที่กำหนด (หากรันอะไรอยู่จะถูกหยุดทำงานทันที) |
| `tmux kill-server` | ปิดระบบ Tmux ทั้งหมดและปิดทุก ๆ Session |

---

### 2. ปุ่มลัดภายใน Session (ต้องกด Prefix `C-b` ก่อนเสมอ)

#### 🔸 การจัดการ Session (Sessions Control)
| ปุ่มลัด | คำอธิบาย |
|---|---|
| **`C-b`** ➔ **`d`** | **Detach** ถอดการเชื่อมต่อเซสชันออกไปทำงานเบื้องหลัง (สำคัญมาก) |
| **`C-b`** ➔ **`s`** | แสดงรายชื่อ Session ทั้งหมดเพื่อสลับการใช้งาน |
| **`C-b`** ➔ **`$`** | เปลี่ยนชื่อ Session ปัจจุบันที่คุณใช้งานอยู่ |

#### 🔸 การจัดการหน้าต่าง (Windows Control - เสมือน Tabs)
| ปุ่มลัด | คำอธิบาย |
|---|---|
| **`C-b`** ➔ **`c`** | **Create** สร้าง Window ใหม่ขึ้นมา |
| **`C-b`** ➔ **`n`** | สลับไปหน้าต่างถัดไป (**N**ext) |
| **`C-b`** ➔ **`p`** | สลับไปหน้าต่างก่อนหน้า (**P**revious) |
| **`C-b`** ➔ **`0` ถึง `9`** | สลับไปยัง Window ตามหมายเลขนั้น ๆ |
| **`C-b`** ➔ **`w`** | แสดงรายการ Window ทั้งหมดในรูปแบบเมนูให้เลือก |
| **`C-b`** ➔ **`,`** | เปลี่ยนชื่อ Window ปัจจุบัน |
| **`C-b`** ➔ **`&`** | ปิด Window ปัจจุบัน (จะมีข้อความยืนยันก่อนปิด) |

#### 🔸 การจัดการช่องย่อย (Panes Control - แบ่งหน้าจอ)
| ปุ่มลัด | คำอธิบาย |
|---|---|
| **`C-b`** ➔ **`%`** | แบ่งหน้าจอแนวตั้ง (ซ้าย-ขวา) |
| **`C-b`** ➔ **`"`** | แบ่งหน้าจอแนวนอน (บน-ล่าง) |
| **`C-b`** ➔ **ปุ่มลูกศร** | เลื่อนไปยังช่อง (Pane) ตามทิศทางที่ต้องการ |
| **`C-b`** ➔ **`o`** | สลับไปยัง Pane ถัดไปวนไปเรื่อย ๆ |
| **`C-b`** ➔ **`;`** | สลับไปยัง Pane ที่เข้าใช้งานล่าสุดก่อนหน้านี้ |
| **`C-b`** ➔ **`z`** | **Zoom** ขยาย Pane ปัจจุบันให้เต็มหน้าจอชั่วคราว (กดซ้ำเพื่อย่อกลับเท่าเดิม) |
| **`C-b`** ➔ **`x`** | ปิด Pane ปัจจุบันที่กำลังใช้งาน (หรือใช้คำสั่ง `exit`) |
| **`C-b`** ➔ **`Ctrl + ปุ่มลูกศร`** | ปรับขนาด (Resize) Pane ปัจจุบันตามทิศทางที่ระบุ (กดค้างไว้เพื่อปรับขนาดได้) |
| **`C-b`** ➔ **`space`** | เปลี่ยน Layout ของ Panes ทั้งหมดใน Window นั้น ๆ วนไปเรื่อย ๆ |

## 🔍 โหมดการคัดลอกข้อความและการเลื่อนหน้าจอ (Copy & Scroll Mode)

เมื่อเราเปิดใช้งาน Tmux หน้าจอ Terminal ปกติจะไม่สามารถใช้เมาส์ Wheel เลื่อนขึ้น-ลงเพื่อดู Log ย้อนหลังได้ เนื่องจาก Tmux เข้ามาควบคุมบัฟเฟอร์หน้าจอ วิธีการจัดการเรื่องนี้มีดังนี้:

### การดูข้อความย้อนหลัง (Scroll-back)
1. เข้าสู่ Copy Mode โดยกด **`C-b`** ➔ **`[`**
2. หน้าจอจะมีบอกสถานะที่มุมขวาบน เช่น `[0/0]`
3. ใช้ **ปุ่มลูกศร**, **Page Up / Page Down** เลื่อนดูประวัติการพิมพ์และ Log ได้ตามปกติ
4. หากต้องการออกจาก Copy Mode ให้กด **`q`**

> [!TIP]
> หากคุ้นเคยกับโปรแกรมแก้ไขข้อความ Vim คุณสามารถเปิดโหมด Vi-Keys สำหรับการค้นหาและเคลื่อนที่ได้สะดวกยิ่งขึ้น (ดูรายละเอียดในหัวข้อถัดไป)

## 🛠️ การตั้งค่าหน้าจอให้ใช้งานง่ายขึ้น (`.tmux.conf`)

คุณสามารถปรับแต่งพฤติกรรมและการจัดแต่งความสวยงามของ Tmux ได้ผ่านไฟล์ Configuration ชื่อ `.tmux.conf` ซึ่งจะสร้างไว้ที่ Home Directory ของผู้ใช้ (`~/.tmux.conf`)

นี่คือไฟล์ตั้งค่าที่แนะนำซึ่งทำให้ Tmux ใช้งานง่ายขึ้นอย่างมาก:

```tmux
# ==========================
#  ไฟล์ตั้งค่าแนะนำ ~/.tmux.conf
# ==========================

# 1. อนุญาตให้ใช้เมาส์ได้ (Mouse Support)
# ช่วยให้เลื่อนหน้าจอขึ้นลง สลับ Pane และเปลี่ยนขนาด Pane โดยใช้เมาส์ได้ทันที
set -g mouse on

# 2. สลับมาใช้ Prefix C-a แทน C-b (เพื่อความถนัดของหลาย ๆ คน คล้ายกับ GNU Screen)
# unbind C-b
# set-option -g prefix C-a
# bind-key C-a send-prefix

# 3. ตั้งค่าให้ Windows และ Panes เริ่มต้นจากเลข 1 (ปกติเริ่มจาก 0)
set -g base-index 1
setw -g pane-base-index 1

# 4. สลับ Pane โดยใช้ปุ่มลัดสไตล์ Vim (Alt + h/j/k/l) โดยไม่ต้องกด Prefix
bind -n M-h select-pane -L
bind -n M-j select-pane -D
bind -n M-k select-pane -U
bind -n M-l select-pane -R

# 5. แบ่งหน้าจอ (Split Pane) ได้เข้าใจง่ายขึ้น
# ใช้ - สำหรับแบ่งแนวนอน และ | สำหรับแบ่งแนวตั้ง
bind | split-window -h -c "#{panel_path}"
bind - split-window -v -c "#{panel_path}"

# 6. ใช้ปุ่มลัดสไตล์ Vim ในโหมด Copy Mode
setw -g mode-keys vi

# 7. ปรับสี Status Bar ให้เรียบหรูโทนสีดำ-เขียว
set -g status-style bg=black,fg=green
```

### วิธีติดตั้งและอัปเดตการตั้งค่า:
1. สร้างหรือเปิดไฟล์ `.tmux.conf`:
   ```sh
   nano ~/.tmux.conf
   ```
2. คัดลอกการตั้งค่าข้างต้นไปใส่และกดบันทึก
3. รีโหลดไฟล์ตั้งค่าโดยพิมพ์คำสั่งภายใน Tmux:
   * กด **`C-b`** ➔ **`:`** เพื่อเปิดช่องพิมพ์คำสั่งของ Tmux
   * พิมพ์คำสั่ง `source-file ~/.tmux.conf` และกด `Enter` (หรือเปิดปิด Session ใหม่)

## 🌟 เคล็ดลับเพิ่มเติม (Pro Tips)

* **ป้องกันกระบวนการหลุดเมื่อเชื่อมต่อ SSH:** หากคุณจำเป็นต้องเปิดโปรแกรมบน Server ค้างคืน (เช่น รัน API Service หรือคำนวณโมเดล AI) ให้รันใน Tmux ทุกครั้ง โดยการสร้าง Session ขึ้นมา รันคำสั่ง แล้วกด `C-b` ➔ `d` เพื่อ Detach จากนั้นคุณสามารถปิดคอมพิวเตอร์กลับบ้านได้เลย เมื่อรุ่งเช้าเชื่อมต่อ SSH เข้ามาใหม่ พิมพ์ `tmux a` คุณก็จะพบหน้าต่างเดิมทำงานต่ออยู่!
* **การกู้คืน Tmux หลังเครื่อง Server Restart:** ตามปกติหากเครื่อง Server รีบูต Tmux session จะหายไป คุณสามารถติดตั้งปลั๊กอินยอดนิยมอย่าง **tmux-resurrect** และ **tmux-continuum** เพื่อทำระบบ Auto Save & Restore ทุก ๆ 15 นาทีได้
